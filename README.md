# 보이스피싱 개입 AI — 2026 금융 AI Challenge

금융보안원 주최 **2026 금융 AI Challenge** 제출용 MVP.

## 문제 정의

보이스피싱의 병목은 **탐지가 아니라 개입**입니다.

은행 창구 직원이 말려도, 경고 문구가 떠도 피해자는 송금합니다. 이미 사기범에게 설득당한
상태라 외부 경고가 "저 사람도 한패"로 해석되는 구간이 존재하기 때문입니다. 즉 위험 점수를
보여주는 것만으로는 부족합니다 — 피해자에게는 그것이 **또 하나의 믿을 수 없는 주장**일 뿐입니다.

그래서 이 서비스는 점수 대신 **반박 근거**를 전면에 놓습니다.

> "'안전계좌'라는 제도는 존재하지 않습니다. 검찰·경찰·금융감독원 어디에도 국민의 돈을
> 대신 보관하는 계좌는 없습니다."

주장이 아니라 **사용자가 스스로 확인할 수 있는 사실**입니다. 설득당한 사람은 주장을
무시하지만 사실은 확인할 수 있습니다. 이것이 이 서비스의 설계 전제입니다.

## 두 개의 단계

`stage` 하나로 사실상 다른 두 제품이 갈립니다.

| 단계 | 목표 | 화면 |
|---|---|---|
| `ongoing` | 아직 송금 전 — 설득을 푼다 | 반박 근거를 크게, 확인 절차를 행동으로 |
| `after_transfer` | 이미 송금함 — 분초를 다툰다 | 요약은 한 줄, 지급정지 절차가 전부 |

## 아키텍처

```
요청 ─▶ RuleEngine (결정론적, 항상 실행)
          │  findings를 컨텍스트로 전달
          ▼
       ClaudeClient (선택적, 구조화 출력)
          │
          ▼
       HybridEngine — 병합 후 응답
```

**중재 규칙(arbitration policy)**

- 룰 엔진은 항상 실행되며 그 점수는 **하한선**입니다. LLM은 점수를 **올릴 수만** 있습니다.
- LLM 호출이 실패하면(키 없음·타임아웃·레이트리밋·거부·파싱 실패) 룰 결과를 그대로 반환하고
  응답에 `degraded: true`를 표시합니다. **서비스는 멈추지 않습니다.**
- 송금 후 긴급 행동은 룰이 소유합니다. 모델은 그 순서를 밀어낼 수 없습니다.

심사 기간(9/7~9/11) 중 API 장애나 크레딧 소진이 나도 서비스가 죽지 않도록 한 설계이자,
안전이 걸린 조언을 확률적 출력에 맡기지 않기 위한 설계입니다.

### 역할 분담

| | 룰 엔진 | Claude |
|---|---|---|
| 담당 | 알려진 수법, 법정 절차, 긴급 행동 | 이 대화에만 있는 조작 정황, 진술 모순 |
| 성질 | 설명 가능·재현 가능 | 유연하지만 검증 불가 |
| 실패 시 | — | 룰 결과로 강등 |

### 모델 설정

- 모델: `claude-opus-5` (`CLAUDE_MODEL`로 변경 가능)
- 사고(thinking)는 Claude Opus 5에서 기본 활성이고 `max_tokens`가 사고와 응답을 **함께**
  제한하므로 기본값을 8192로 두었습니다. 줄이면 응답이 잘릴 수 있습니다.
- 출력은 Pydantic 스키마(`LLMAnalysis`)로 강제되어 파싱 실패가 구조적으로 차단됩니다.

## 실행

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env          # 키 없이도 룰 전용으로 동작합니다
uvicorn app.main:app --reload
```

테스트:

```bash
pytest
```

## API

| 메서드 | 경로 | 설명 |
|---|---|---|
| `GET` | `/health` | 상태 확인. `llm_enabled`로 LLM 경로 활성 여부 확인 |
| `POST` | `/api/analyze` | 위험 점수·반박 근거·대응 행동 반환 |
| `GET` | `/docs` | FastAPI 자동 생성 OpenAPI 문서 |

상세 스펙은 [`docs/api-spec.md`](docs/api-spec.md)를 참고하세요.

```bash
curl -X POST localhost:8000/api/analyze \
  -H 'Content-Type: application/json' \
  -d '{"text":"검찰인데 안전계좌로 이체하고 아무에게도 말하지 마세요","stage":"ongoing"}'
```

## 디렉터리

```
app/
  core/config.py     환경변수 기반 설정
  ai/schemas.py      요청·응답 계약 (rebuttal·stage 포함)
  ai/rules.py        결정론적 룰 엔진
  ai/rulesets.py     보이스피싱 룰셋 — 수법·반박 근거·행동
  ai/client.py       Claude 어댑터 (실패 시 None 반환)
  ai/engine.py       하이브리드 오케스트레이터 + 중재 규칙
  main.py            FastAPI 엔트리포인트
tests/               룰·중재·구조 불변식·API 테스트
docs/api-spec.md     기능 명세서용 엔드포인트 정리
```

## ⚠️ 제출 전 반드시 확인할 것

**`app/ai/rulesets.py`의 신고 전화번호와 법적 절차는 일반 지식으로 작성되었으며 공식
출처로 검증되지 않았습니다.** 잘못된 긴급 안내는 안내가 없는 것보다 해롭습니다. 금융감독원·
경찰청 공식 자료와 대조해 `CONTACTS` 블록과 송금 후 행동 문구를 갱신하세요.

그 외 남은 작업:

- 프론트엔드 (단계별 화면 2종)
- 실제 Claude API 호출 검증 (현재 테스트는 전부 스텁)
- 배포 (`render.yaml` 참고)

## 데이터 출처

룰셋은 **공개된 보이스피싱 수법·대응 요령을 참고해 직접 작성**했으며 외부 데이터셋을
포함하지 않습니다. 외부 데이터를 추가할 경우 출처와 라이선스를 이 섹션에 명시합니다.

## 한계

- 룰은 한국어 키워드 매칭입니다. 표현이 변형되면 룰은 놓치고 LLM이 받습니다.
- 합성 시나리오 기반이므로 실제 통화 데이터에 대한 탐지율은 측정되지 않았습니다.
- 음성 입력(STT)은 범위 밖입니다. 텍스트 입력만 받습니다.
